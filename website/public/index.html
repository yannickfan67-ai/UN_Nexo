CURRENT SCOPE

下載限定版

目前版本提供檔案下載管理，不包含帳號登入、遊戲啟動或伺服器連線。下載不代表取得遊戲授權；遊玩仍需合法持有 Java Edition，並使用具有登入與所有權驗證的啟動器。

版本搜尋

正式版、快照與歷史版本。離線時可瀏覽已快取的目錄。

持久下載佇列

加入多個版本，暫停後手動恢復。重開後保留未完成任務。

校驗與修復

重新使用通過校驗的完整檔案，只下載缺失或損壞內容。

本機管理

獨立版本資料夾、重新命名、開啟目錄和最少資料的下載報告。
